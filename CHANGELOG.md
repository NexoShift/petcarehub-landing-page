# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

+ ## 1.0.0 - 2026-11-12

### Added

- Responsive landing page with hero, about the product, AI features, benefits, plans, about the team, FAQ and call to action sections.
- Shared header, footer and language switcher loaded by `main.js` from `_header.html`, `_footer.html` and `_language-switcher.html`.
- Spanish and English internationalization, with Spanish as the default language.
- Video frames for "About the product" and "About the team", configured in `config.js`.
- Plans in US dollars: Owner ($9), Professional ($29) and Clinic ($79).
- Team member profiles of the five NexoShift members.
- Terms of Service and Privacy Policy (Ley N° 29733) pages.
- GitHub Actions workflow that deploys `public/` to GitHub Pages on every push to `main`.
- README, CONTRIBUTING, CHANGELOG and MIT LICENSE.
